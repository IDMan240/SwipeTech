KESWILL STEVE LIGHTING WEBSITE
==============================

HOW TO RUN IN XAMPP
1. Extract the whole ZIP into C:\xampp\htdocs\
2. Make sure the extracted folder is named: keswill-steve-lighting
3. Open XAMPP Control Panel and start Apache.
4. Visit: http://localhost/keswill-steve-lighting/

FILES
- index.html: site content
- style.css: responsive design and stage-lighting effects
- script.js: mobile menu, gallery lightbox, booking-to-WhatsApp form
- images/: your logo and four uploaded event photos
